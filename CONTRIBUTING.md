# Como Contribuir

1. Crie uma branch para sua funcionalidade (\`git checkout -b feature/minha-funcionalidade\`).
2. Garanta que o código passa na verificação estática e de tipos (\`npm run build\`).
3. Adicione testes para novas funcionalidades e garanta que todos passam (\`npm run test\`).
4. Envie um Pull Request detalhando o objetivo e as alterações.
